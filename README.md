# Siddharth Bilapati — Portfolio

Portfolio Starter

This is a minimal static portfolio site. Two quick ways to run it locally using PowerShell:

1) If you have Python 3 installed (recommended):

```powershell
# from inside the portfolio-website folder
python -m http.server 8000
# then open http://localhost:8000 in your browser
```

2) If you have Node.js installed, use the tiny "serve" package:

```powershell
# install once globally
npm install -g serve
# from inside the portfolio-website folder
serve -l 8000
# then open http://localhost:8000 in your browser
```

Files:
- `index.html` — main page
- `styles.css` — starter styles
